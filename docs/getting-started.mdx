# Getting started

EasySupport is a self-hosted bot + website. This guide walks you through creating the bot, configuring the environment, installing, and setting up a guild.

## Requirements

- Node.js **22.5 or newer**
- A MySQL database
- A Discord application and bot token from the [Discord Developer Portal](https://discord.com/developers/applications)
- The bot's Discord role needs **Manage Channels** and **Manage Roles**, along with the messaging, attachment, embed, and history permissions used by your enabled features

Panel art is rasterized with `@resvg/resvg-js`. Category artwork is cached under `data/art/`; transcripts are written under `transcripts/`.

## 1. Create and invite the bot

1. Create an application in the Discord Developer Portal and add a bot.
2. Copy the bot token. Under **Bot → Privileged Gateway Intents**, enable **Server Members Intent** and **Message Content Intent**.
3. Generate an invite using the `bot` and `applications.commands` scopes. Grant the permissions needed by the bot's enabled features.
4. For the web dashboard, configure the Discord OAuth2 client and its callback URL to match the `OAUTH_REDIRECT_URI` value in your environment.

## 2. Configure environment

Copy the example and fill in the values for your Discord application and MySQL database:

```bash
cp .env.example .env
```

The required settings include `DISCORD_TOKEN`, `CLIENT_ID`, `CLIENT_SECRET`, `MYSQL_HOST`, `MYSQL_USER`, `MYSQL_PASSWORD`, `MYSQL_DATABASE`, and `OAUTH_REDIRECT_URI`. Set a unique `SESSION_SECRET` for production. `MYSQL_PORT`, `PORT`, and `GUILD_ID` are optional overrides; see [`.env.example`](./.env.example) for the complete list.

For a public deployment, set the OAuth callback to your deployed website's `/auth/callback` route and add the same URL in the Discord Developer Portal. The web server trusts one reverse proxy for forwarded client IPs, as required by hosted deployments using `X-Forwarded-For`.

<CodeGroup>
  <CodeGroupItem title=".env.example" active>
```ini
# Discord application credentials (from Discord Developer Portal)
DISCORD_TOKEN=your-bot-token-here
CLIENT_ID=your-application-id-here
CLIENT_SECRET=your-client-secret-here
GUILD_ID=your-dev-guild-id-here

# MySQL storage (required — replace with your credentials)
MYSQL_HOST=your-mysql-host
MYSQL_PORT=3306
MYSQL_USER=your-mysql-user
MYSQL_PASSWORD=your-mysql-password
MYSQL_DATABASE=your-mysql-database

# Website port (combined bot + web process)
PORT=3000

# Express session secret (change this in production)
SESSION_SECRET=your-session-secret-here

# Discord OAuth2 redirect URI (must match Discord Developer Portal)
OAUTH_REDIRECT_URI=http://localhost:3000/auth/callback
OAUTH_SCOPE=identify guilds
```
  </CodeGroupItem>
</CodeGroup>

## 3. Install, register, and start

```bash
npm install
npm run deploy
npm start
```

The deploy command synchronizes slash commands from `src/commands/` with Discord. It also removes commands that are no longer present in the current build.

## 4. Configure a guild

Use `/setup` for ticket defaults and `/panel` to publish the ticket panel. Guild administrators can use the web dashboard to configure supported modules and staff role permissions.

<Steps>
  <Step title="Run /setup">
    Bind a staff role, log channel, and ticket category to the guild.
  </Step>
  <Step title="Run /panel">
    Post the ticket panel so members can open support tickets.
  </Step>
  <Step title="Configure in dashboard">
    Sign in with Discord and tune modules, categories, and role access per guild.
  </Step>
</Steps>

## Hosting and operations

The bot stores its data in the configured MySQL database, generated artwork in `data/art/`, downloaded emoji SVGs in `data/emoji/`, and transcripts in `transcripts/`. For production:

- Run under **systemd** or **PM2** so the process restarts after a reboot.
- Back up the MySQL database regularly.
- Keep `.env` out of version control and never publish bot or database credentials.

Example systemd service:

```ini
[Service]
WorkingDirectory=/opt/easysupport
ExecStart=/usr/bin/node src/index.js
Restart=always
EnvironmentFile=/opt/easysupport/.env
```
