# Configure a guild

Use `/setup` for ticket defaults and `/panel` to publish the ticket panel. Guild administrators can use the web dashboard to configure supported modules and staff role permissions.

## Step 1 — Run /setup

Bind a staff role, log channel, and ticket category to the guild.

## Step 2 — Run /panel

Post the ticket panel so members can open support tickets.

## Step 3 — Configure in dashboard

Sign in with Discord and tune modules, categories, and role access per guild.

The web dashboard lets you configure per guild:

- Supported modules, channels, categories, and role settings
- Role-based access to commands; server administrators retain their bypass
- Searchable guild, channel, category, and role selectors
- Clear save and loading feedback while settings are updated

**You're all set!** Your EasySupport instance is ready to use. Check the [Dashboard](/dashboard) guide for more details on the web interface.
